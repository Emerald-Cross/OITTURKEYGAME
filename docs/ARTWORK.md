# Christmas artwork

All eight SVG assets are original native vectors generated by `scripts/build-art.py`. No stock imagery, external fonts, raster atlas, or third-party image license is needed. Rebuild using the Python standard library. Runtime serves the committed SVGs directly.

| File | Purpose |
| --- | --- |
| `winter-village.svg` | Moon, stars, aurora, snowy mountains, fir forest, lit cabins, a Christmas tree, and snowdrifts |
| `winter-cover.svg` | Foreground snow-covered boughs, mirrored on the right |
| `snowman.svg` | Cream snow, red wool hat, green scarf, twig arms |
| `gift.svg` | Gold parcel and red ribbon |
| `santa.svg` | Santa carrying the large labeled parcel |
| `reindeer.svg` | Antlers, red scarf, pale code blanket |
| `snow-burst.svg` | Snow, snowflakes, and gold ribbon hit particles |
| `snowflake.svg` | Local favicon |

Characters use a 1000 × 1000 coordinate system. The only active code is a separate square image at left 26%, top 39%, width 48% of the character. It is integrated into the snowman's body, gift label, Santa's parcel, or reindeer's blanket. At a 1920 × 1080 viewport it is approximately 492 px square. Each QR has a four-module white quiet zone. There is no tint, mask, perspective, or animation on the code while it is available to scan.

Characters move as complete billboards along the shared approach/peek/dodge/retreat paths. No crop mask is applied to art. Codes are hidden before movement and synchronously on a successful scan. Snow and ribbon impacts happen after code concealment. Penalty labels remain above a still-active hold-fire code. Foreground boughs stay at the scene edges. Reduced motion removes travel, snowfall, and tumbling while preserving scoring timing and static hit feedback.

No dialogue beyond Brrr! and Ho ho ho. Sound consists of optional synthesized snow puffs and bell partials. It starts only after a user gesture.
