# Christmas edition

This edition starts from `Emerald-Cross/OITTURKEYGAME` at commit `eddb6f42aed1faa3c7187429465cf8c12dd48f10` and is maintained on the separate `christmas` branch. The turkey game's `main` branch is unchanged.

The connected GitHub tools cannot create a repository. To make a fully independent repository later, create an empty repository named `OITCHRISTMASGAME`, then push this branch there as `main`. No application changes are required.

The Christmas game has its own QR payloads, WebSocket protocol name, and leaderboard ruleset. Use a separate server and data directory for each edition.
